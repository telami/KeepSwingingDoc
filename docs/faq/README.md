# 常见问题汇总

## 安装后 Watch 上找不到 App
正常情况下手机 App 安装后，会同时将 Watch App 安装到手表。
但电量不足，网络不稳定等情况下，可能会导致手表 App 安装不成功。

解决方案：
1. 从 Apple Watch 上的 App Store 上搜索"挥拍吧"下载安装
2. 切换网络，推荐使用流量下载
3. 重启手机和 Watch，或者卸载重装

## 没有显示卡路里、心率

主要是因为第一次启动时权限没有打开

解决方案：

1. 手机app上：
- 打开「设置」->「隐私」->「健康」->「挥拍吧」->「打开所有类别」

2. 手表app上：
- 打开「设置」->「健康」->「App」->「挥拍吧」->「打开所有类别」

## 挥拍等运动数据不准，次数过少或者显示为 0

可能造成的原因：

1. 如果同时打开了系统健身训练中的「羽毛球」模式，「挥拍吧」将无法获得传感器数据，数据将显示为 0。请注意「挥拍吧」会自动同步到体能训练中，记录在「健身」中，不需要再打开系统的羽毛球模式

2. 将手表的「挥拍吧」开启后退出到后台，会计数为 0。因为退出到后台「挥拍吧」会被手表强制关闭的，所以使用中请保持前台显示

3. 检查是否处于低电量模式，低电量模式会限制传感器采集

4. 如果以上原因都未解决，请尝试重新安装手机 App 和手表端 App，或者尝试重启

**心率和卡路里数据均直接由 WatchOS 计算得出，会根据体重、心率、年龄、性别等因素相关，并不完全是线性结果。**

## 手机端没有同步数据记录

可能造成的原因：
1. 手表电量太低或处于低电量模式
2. 隐私授权没有打开（具体操作，请参照问题二）
3. 系统不一致，将 WatchOS 和 iOS 系统版本同时更新至最新

解决办法：

**1. 点击手表 app 右上角的设置按钮，选择训练记录，点选需要同步的数据**

2. 如果仍然无法同步，你可能需要重新配对你的手表，或者升级手表的系统至最新
